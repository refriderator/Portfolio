Jarvis

October 18, 2026 · Software

https://github.com/refriderator/Jarvis

Jarvis is a Mac assistant that lives in the notch. You click the notch or press Option-Space, then talk or type. It answers with a caption and a voice, and it can set timers, read my calendar and Notion, open apps and hold windows for me.

I wanted something that felt like part of the Mac instead of another chat window. The notch is dead space on every new MacBook, so that is where it lives.

The dock

My favourite part. Drag a window by its title bar onto the side of the screen and it slides off, leaving a sliver showing. Point at the edge and cards of the held windows pop out; click one to use it, and it slides away again when you move off. Drop a window on the notch and it goes into the notch instead.

Try it below (works with touch too). It is a toy version in the browser, but it behaves like the real thing.

A bit of physics

Springs. Every animation is a damped spring, the same x″ + 2ζωx′ + ω²x = 0 from first year mechanics. The damping ratio ζ sets the feel. Overshoot is e−ζπ/√(1−ζ²), so the notch hopping between displays (ζ ≈ 0.5) overshoots about 16% and feels bouncy, while the notch opening (ζ ≈ 0.82) overshoots about 1% and just feels smooth.

Hysteresis. A window is caught when the pointer comes within 12 pt of an edge, but only let go once it is 70 pt away. With one threshold, a shaky hand sitting on the line flickers between caught and not caught. Two thresholds is the same idea as a Schmitt trigger or a magnet's B–H loop.

Sampling rate. Jarvis has to ask macOS where other apps' windows are, and each ask waits on that app. I first checked 30 times a second with the default 6 s timeout. One busy app could then freeze a frame that only has 16.7 ms (at 60 fps) for hundreds of frames. Checking twice a second with a 0.5 s timeout was plenty and the stutter went away.

How it’s built

It is written in Swift (SwiftUI and AppKit) as a plain Swift package, about 17,000 lines across 176 files, with a rule of one job per file and under about 300 lines each. The logic lives in its own library so it can be tested without opening the app.

Answers go through tiers, cheapest first:

  • Plain code for fixed commands like timers and reminders. Instant and free.
  • Apple’s on-device model for summarizing text already on screen.
  • A small local model I trained myself for tool jobs (next post).
  • Claude or ChatGPT for anything that needs real knowledge or writing.

Code decides which tier, never a model, since asking a model to decide would add a whole extra call to every question. Most questions never leave the Mac.
